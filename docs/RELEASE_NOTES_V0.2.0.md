# Soulvise Plmate v0.2.0

Soulvise Plmate 是一个“Agent 的个性化 Agent”：它把本机AI Agent的聊天、视觉、知识和项目能力，与桌面角色、个性认知、监督、陪看和情绪反馈组合在一起。

## 支持的操作系统

- **正式支持：Windows 10/11 64位**，提供安装器与免安装便携版。
- **暂未正式支持：macOS、Linux**。源码保留跨平台架构与安全降级设计，但本版本不提供对应安装包，截图权限和窗口后端仍待实现。

## 本版本官方功能

- 暮色小镇界面、系统托盘和六种动态角色状态。
- Windows桌面角色拖动、吸附、跟随、全屏冻结、归位与完全退出。
- 监督与陪看共用的统一截图和分析管线。
- 基础与自定义监督认知、语义风险判断、角色生气反馈及安全视频跳转。
- 同主题兴趣判断、高兴值、应景气泡、100分奖杯记录和庆祝后初始值复位。
- 简化认知编辑、监督/陪看隔离、观察历史和需用户确认的AI整理草稿。
- Codex专用深度连接。
- Claude、Gemini与自定义可信程序的ACP连接。
- 主Agent切换，以及聊天、视觉、监督、认知整理、气泡、研究和项目辅助的单项能力覆盖。
- API密钥系统密钥库存储、临时截图清理、迟到结果失效和只读观察会话等隐私控制。

ACP提供协议兼容，但不能让任意程序自动获得全部能力。只有Agent真实声明、用户授权且通过自检的能力才会启用。

## 下载与校验

Release提供以下三个文件：

- `Soulvise-Plmate-Setup-v0.2.0-Windows-x64.exe`
- `Soulvise-Plmate-v0.2.0-Windows-x64.exe`
- `SHA256SUMS.txt`

安装器和程序当前尚未进行代码签名，Windows可能提示“未知发布者”。请从本仓库Release下载，并在运行前核对SHA-256。

## 隐私提醒

观察功能首次启动时保持关闭。本项目不支持隐藏监控或远程监控。连接视觉Provider前，请确认所选Agent的来源、权限和数据政策；程序不会把API密钥、Agent令牌或原始截图提交到GitHub。
